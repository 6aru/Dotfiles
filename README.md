## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/6aru/Dotfiles.git
```

Copy the configuration you want:

```bash
cp -r Dotfiles/.config/<application> ~/.config/
```

Example:

```bash
cp -r Dotfiles/.config/kitty ~/.config/
```

or

```bash
cp -r Dotfiles/.config/fastfetch ~/.config/
```
